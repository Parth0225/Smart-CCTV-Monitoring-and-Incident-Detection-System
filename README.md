# Smart CCTV UI

Frontend prototype for the Smart CCTV Monitoring and Incident Detection System.

## Run

Open `index.html` in a browser, or run a local static server:

```powershell
cd smart-cctv-ui
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included screens

Login, registration, dashboard, live feed, detection mode, incident alert, incident detail, incidents, history, settings, and logout.

All data and detection actions are frontend demonstrations until the Flask backend is added.
